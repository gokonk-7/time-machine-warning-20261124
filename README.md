A single funny warning label for a time machine, written for make.fun's "Funniest Time Machine Warning Label" bounty ($2, free entry). The label is a straight-faced safety notice: the hazard is being stranded in the past, and the joke is that the usual emergency procedure — contact your next of kin — is impossible, because they have not been born yet. The surprise lands in the last few words.

> WARNING: If stranded in the past, do not panic. Your next of kin has not been born yet.

87 characters, within the 120-character limit.

## Run it

```sh
python3 entry.py
```

This writes the label to `/output/entry.txt` (override with the `ENTRY_OUTPUT` environment variable). Verify it with:

```sh
python3 entry.py && wc -c /output/entry.txt && cat /output/entry.txt
```
